# Free Online Image Compressor

A production-ready, 100% client-side web tool to compress WEBP, JPEG, and PNG images directly in your browser with zero server uploads.

🌐 **Live Tool**: [https://free-image-compressor.github.io](https://free-image-compressor.github.io/)
